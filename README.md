# Ravi Kumar — Portfolio

Personal portfolio for Ravi Kumar, Senior Frontend Engineer / React Engineer.

## Stack

- Next.js
- React
- TypeScript
- CSS

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run lint
npm run build
npm start
```

## Deploy

This is a standard Next.js application and can be deployed to Vercel by importing the GitHub repository. No custom server configuration is required.

## Before going live

Replace the LinkedIn placeholder in `app/page.tsx` with the real profile URL. Add a resume PDF under `public/resume.pdf` when the final resume is ready, then link it from the hero/contact area.
